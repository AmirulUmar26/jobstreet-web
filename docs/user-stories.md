# User Stories

1. As an employer, I want to state when interns can start and how long they can stay, so that students can check whether the placement meets their university requirements.
2. As a student, I want to filter internships by my required start date and placement duration, so that I can shortlist opportunities that fit my university schedule.
3. As a student, I want to see the accepted start dates and duration directly in the search results, so that I can compare internships without opening each listing.
