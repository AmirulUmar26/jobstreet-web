# User Stories

1. As an employer, I want to state when interns can start and how long they can stay, so that students can check whether the placement meets their university requirements.

Linked requirements: FR1, FR2

Acceptance criteria:

The employer must select a start-availability option and a duration option before publishing the internship.

The published listing displays these conditions, including “Flexible” or “Negotiable” when selected.

2. As a student, I want to filter internships by my required start date and placement duration, so that I can shortlist opportunities that fit my university schedule.

Linked requirements: FR3, FR4, FR6

Acceptance criteria:

A student requesting a 1 March 2027 start and a five-month placement sees “Matches” for a listing accepting March starts and placements lasting three to six months.

Selecting the “Matches” filter displays only listings classified as “Matches”.

3.As a student, I want to see the accepted start dates and duration directly in the search results, so that I can compare internships without opening each listing.

Linked requirements: FR1, FR2

Additional requirement: FR7 — The system shall display the employer’s placement start availability and accepted duration on each search result.

Acceptance criteria:

Each search result displays the employer’s stated start availability and accepted placement duration.

Flexible or negotiable conditions are clearly labelled “Flexible” or “Negotiable”.
